Commit messages, written by the agent you already pay for.

gitcap hands your staged diff to Claude Code, Codex, Gemini, Grok, or whichever coding agent you're logged in to, and gives you back a clean Conventional Commit. No new API keys. When one agent's plan runs out, the next one takes over.

$ uv tool install gitcap

then stage something and run gitcap commit

a1f3e9c How it works

  1. It finds your agents

    gitcap reads only what's already on your machine: agent programs on your PATH, their login files, and how recently their session logs changed. The agent you used last goes first. It never opens your tokens.

  2. Your agent writes the message

    The agent runs once, in its non-interactive mode, inside an empty temporary folder with its tools switched off, so it can't read or change your repo. You review it: c commit, e edit, r regenerate.

  3. The next one takes over

    Plan expired, credits gone, logged out? gitcap moves to your next agent, then a local model, then Groq's free API. An agent that failed waits at the back of the line until it works again. gitcap only gives up when there's nothing left to try.

e52d81a Small things that add up

You see what it cost
Every message shows the agent, the model, how long it took, and the exact token counts and cost the agent reported.
Big diffs still fit
The diff is trimmed separately for each backend. Every file keeps its header, lockfiles are left out, and when a backend says the prompt is too large, gitcap shrinks it and retries.
Fast to start
No AI SDKs to load: two small dependencies. A check for updates runs in the background and never slows a command down.
Matches your history
Recent commit subjects go into the prompt, so new messages follow the scopes and style your repo already uses.

0b9e6f4 Commands

gitcap commitWrite a message for staged changes, review it, commit. Works from any folder in the repo.
gitcap commit -nDry run: print the message only.
gitcap commit -yCommit without reviewing.
gitcap commit -c "hotfix for login"Give the agent extra context.
gitcap commit -a grokUse only this agent, this once.
gitcap agentsYour agents, in the order they'll be tried, with any that are paused and why.
gitcap agents --retryGive paused agents another chance right away.
gitcap config --agent claudeTry this agent first; the rest stay as fallback.
gitcap config --groq-key gsk_…Add Groq's free API as a last resort.
gitcap upgradeUpdate to the latest release (uv tool, pipx or pip).
gitcap uninstallRemove gitcap, its settings and caches.
